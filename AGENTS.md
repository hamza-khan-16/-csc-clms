# CLMS — Chandrabhan Sharma College Leave Management System

This project uses TanStack Start (React + TypeScript) with Supabase for auth and data.

## Stack
- **Frontend**: React 19, TanStack Router/Start, Tailwind CSS v4
- **Backend/DB**: Supabase (Postgres, Auth, RLS)
- **Build**: Vite 8, Bun

## Dev
```bash
bun install
bun dev
```

## Env
Copy `.env.example` to `.env` and fill in your Supabase project values:
```
SUPABASE_URL=
SUPABASE_PUBLISHABLE_KEY=
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```
